# Keep a Changelog

Starter note, from https://keepachangelog.com/ (version 1.1.0), not yet
checked against projects that use it.

## What it is

A convention for a hand-written CHANGELOG.md: one section per release,
newest first, with changes grouped as Added, Changed, Deprecated,
Removed, Fixed and Security, and an Unreleased section at the top.

## Ideas worth taking

- **Write for people, not machines.** adopt (0.1.0). Our version notes
  describe concrete changes in plain words, never commit hashes.
- **An Unreleased section that collects changes as they land.**
  consider. WHATNOW's STATE plays this part today; a release might want
  the notes gathered in one place.

## Things to avoid

- **A CHANGELOG.md in every repository.** reject for now. ROADMAP.md
  says what each version delivers and the work records say how; a third
  file would drift from both.
